# 🌾 Sugar Factory Management System

![Banner]![alt text](<Screenshot 2026-06-21 183423-1.png>)

## 📖 Project Overview

The **Sugar Factory Management System** is a full-stack web application developed to streamline sugar factory operations. The system enables efficient management of farmers, workers, sugarcane details, and field locations through an interactive dashboard and map integration.

---

## ✨ Key Features

### 🔐 Authentication & Authorization

* Admin and Worker Login
* Role-Based Access Control
* Secure Session Management

### 👨‍🌾 Farmer Management

* Add New Farmers
* Update Farmer Information
* Delete Farmer Records
* View Complete Farmer Database

### 👷 Worker Management

* Create Worker Accounts
* Manage Worker Details
* Assign Farmers to Workers

### 📍 Location Tracking

* Live GPS Location Capture
* Interactive Leaflet Maps
* Farmer Field Location Tracking
* Village Search Functionality

### 🌱 Sugarcane Management

* Sugarcane Variety Selection
* Planting Date Records
* Acre Management
* Farm Details Storage

### 📊 Dashboard & Analytics

* Farmer Statistics
* Worker Information
* Data Monitoring Dashboard
* Quick Access Navigation

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/SakshiJadhav0507/Sugar-Factory-Management-System.git
cd Sugar-Factory-Management-System
```

### Install Dependencies

```bash
npm install
```

### Start MongoDB

```bash
mongod
```

### Run Backend Server

```bash
node server.js
```

Server will start at:

```text
http://127.0.0.1:5000
```

### Run Frontend

Open:

```text
home.html
```

or use VS Code Live Server.
